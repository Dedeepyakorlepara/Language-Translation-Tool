
# Language Translation Tool

## Project Description
The Language Translation Tool is a web-based application
that helps users translate text from one language to another.

## Technologies Used
- HTML
- CSS
- JavaScript
- MyMemory Translation API

## Features
- User-friendly interface
- Source language selection
- Target language selection
- Multiple language support
- Instant text translation
- Swap languages option
- Copy translated text
- Empty input validation

## How to Run
1. Download or extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Enter the text to translate.
5. Select source and target languages.
6. Click the Translate button.
7. View and copy the translated result.

## API Used
MyMemory Translation API:
https://api.mymemory.translated.net/get
